Step 1: Basic Flashlight Setup & Lens Focus Adjustment

Configure flashlight basic setup and save flashlight basic configuration before proceeding. Usually default setup / mapping is sufficient. Reconfiguration is only required if a customization is needed, e.g. drive additional external LEDs, use specific pin or use of specific LED type, ...
After image is visible in preview, adjust lens focus until image is as sharp as possible. Detailed instructions are available in the focus adjustment guide
Verify that the flashlight does not create glare in critical processing areas. If the internal LED is insufficient or glare cannot be avoided, refer to Installation of external LEDs or to discussion Ways to avoid reflections.

Note 1: Any pending image refresh is blocking saving or step change.
Note 2: Camera parametrization and flashlight fine-tuning is performed in next step.
